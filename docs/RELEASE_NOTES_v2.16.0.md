# FlukeEventView v2.16.0 — первый публичный релиз

Открытая реализация программы **EventView V2.16** для регистратора качества электроэнергии
**Fluke VR101 / VR101S** (OEM ACR PowerWatch) на C# / WinForms (.NET Framework 4.7.2).
Оригинальный `EV101.EXE` — 16-битное приложение Visual Basic 3.0, которое запускается только
через эмуляцию Win16; этот проект повторяет его функциональность на современной платформе.

## Возможности

**Работа с прибором**
- Обмен через оптический адаптер Lite-Link (9600-N-8-1, питание адаптера по DTR/RTS).
- Фоновый опрос состояния: напряжение фаза–нейтраль, нейтраль–земля, частота, наработка.
- Чтение уставок, выгрузка журнала событий блоками по 32 события, проверка контрольных сумм.
- Запись уставок и очистка памяти прибора одним действием.
- Индикаторы ONLINE / TX / RX, протокольный лог в окне и в файле `FlukeEventView.log` (включая
  строки `RAW:` с сырыми байтами канала N-G и байтом конфигурации).

**Анализ**
- Декодирование 8-байтовых записей: тип, амплитуда, длительность, фаза импульса, метка времени.
- Классы: H-N Swell/Sag/Transient, N-G Swell/Transient, High/Low Frequency, Outage, Open Event,
  Loss of Synchronization (обнаружение по сбросу наработки прибора).
- Фильтры по типу и интервалу даты/времени, сводные счётчики, пометка «(не сохранено)».
- Учёт минимума и максимума напряжения и частоты за сессию.
- Три графика: события за период, распределение «длительность — амплитуда» с легендой
  HN / NG / Outage and Spikes, осциллограмма одиночного импульса на синусоиде.
- Сохранение графиков в PNG / BMP / JPG, печать отчёта с предпросмотром.

**Профили порогов (новое)**
12 наборов в один клик. **Арбитражные (★)** — по нормативным документам, для сопоставления
результатов с требованиями:

| Профиль | Sag | Swell | Частота |
|---|---|---|---|
| ★ ГОСТ 32144-2013: ±10 % / ±0,2 Гц | 198 В | 242 В | 49.8 … 50.2 Гц |
| ★ ГОСТ 32144-2013: ±10 % / ±0,4 Гц | 198 В | 242 В | 49.6 … 50.4 Гц |
| ★ EN 50160: ±10 % / ±1 % | 198 В | 242 В | 49.5 … 50.5 Гц |
| ★ ANSI C84.1 Range A: ±5 % | 210 В | 230 В | 49.5 … 50.5 Гц |
| ★ IEC 61000-2-4, класс 2: ±10 % | 198 В | 242 В | 49.5 … 50.5 Гц |

**Сценарии** — практические наборы под объект: чувствительная нагрузка (±7,5 %), серверная/ЦОД
с провалами до −15 %, промышленный объект с двигателями, ИБП/резервное питание, диагностика
сети (±2 %), только тяжёлые отклонения (±20 %), базовый заводской набор.

Пороги импульсов и N-G профилями не меняются: единого норматива для них нет.

**Файлы и интерфейс**
- Чтение и запись файлов сессии `.VER` (формат EventView V2.x, число событий — по длине файла).
- Экспорт в CSV; двуязычный интерфейс RU/EN; масштабирование шрифта (A- / A+ / 100 %, Ctrl+колесо).
- Окно VR101 Calibration — расчёт поправочного коэффициента по внешнему вольтметру.
- Иконка приложения в виде корпуса регистратора (жёлтый прямоугольник с чёрной верхней третью).

## Изменения по сравнению с оригиналом

- Работает на 64-битной Windows без эмулятора Win16.
- Не теряет данные при закрытии: события сохраняются в `.VER`, пока пользователь не решит иначе.
- Дополнительно: RAW-диагностика канала N-G, профили порогов, печать отчёта, фильтры, графики.
- Не реализовано: модемное подключение (PhoneBook / Modem Setup) и запись калибровки в прибор
  (формат хранения не подтверждён).

## Проверено

- Сборка: MSBuild 16 (VS2019), .NET Framework 4.7.2 — 0 ошибок, 0 предупреждений.
- Живой обмен с регистратором F28045 (прошивка 9): заголовок 88 байт + CRC, блок событий
  263 байта + CRC, серийный номер и пороги совпадают с оригинальным EventView.
- Профиль «★ ГОСТ 32144-2013: ±10 % / ±0,2 Гц» записан в прибор и проверен обратным чтением
  (Sag 198 В, Swell 242 В, 49.78 / 50.22 Гц).

## Установка

1. Скачайте архив релиза или соберите из исходников (`FlukeEventView.sln`, VS2019).
2. Требуется .NET Framework 4.7.2 и COM-порт с адаптером Lite-Link.
3. Подключите адаптер к COM-порту ПК, запустите программу, выберите порт, нажмите «Старт опроса»
   и вставьте «глазок» адаптера в окно ИК-порта регистратора.
