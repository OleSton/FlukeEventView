# Профили порогов

Прибор VR101 умеет следить только за несколькими порогами, поэтому любой «нормативный» набор
сводится к четырём числам: **Sag** (просадка), **Swell** (всплеск) и **Min/Max частоты**.
Профиль подставляет эти значения в поля вкладки «Статус»; запись в прибор — отдельным
действием **«Записать уставки / Очистить память прибора»** (оно же очищает журнал событий).

Профили делятся на два вида:

* **Арбитражные (★)** — значения взяты из нормативных документов. Это опорные наборы: их
  используют, когда результат нужно сопоставить с требованиями ГОСТ, EN, IEC или ANSI.
  Обоснование и ссылки — в разделе «Источники».
* **Сценарии** — практические наборы под конкретный объект и задачу. Нормативной силы не
  имеют: это инженерный выбор порогов под тип нагрузки и цель обследования.

Пороги импульсов (Transient) и канала N-G профилями **не меняются**: единого числового
норматива для них нет, они зависят от объекта и типа сети.

## Округление под шаг прибора

Прибор хранит пороги целыми байтами, шаг задан жёстко:

* пороги H-N — **2 В** (в режиме 220 В), диапазоны программы: Swell 100…300 В, Sag 60…240 В;
* пороги частоты — **0,1 Гц**, Min 45.0…49.9 Гц, Max 50.1…55.0 Гц;
* между Sag и Swell должна оставаться мёртвая зона (программа проверяет автоматически).

Поэтому «идеальные» ±5 % (209…231 В) из ANSI приведены к 210/230 В — то есть в сторону более
**строгого** контроля: просадка ловится раньше, всплеск раньше. Частотные слова считаются как
`word = round(57600 / f)`, поэтому после записи прибор показывает 49.78 / 50.22 Гц, а программа
отображает 49.8 / 50.2 Гц.

## Источники

* **ГОСТ 32144-2013** «Нормы качества электрической энергии в системах электроснабжения
  общего назначения»: 220 В, отклонения ±10 % (198…242 В); частота ±0,2 Гц для 95 % времени
  недели и ±0,4 Гц для 100 % времени.
* **EN 50160** «Voltage characteristics of electricity supplied by public distribution
  networks»: частота 50 Гц ±1 % (49,5…50,5 Гц) для 99,5 % года; напряжение ±10 % для 95 %
  времени недели (10-минутные RMS).
* **ANSI C84.1** Range A: 114…126 В на базе 120 В — ±5 % для установившихся значений.
* **IEC 61000-2-4**, класс 2: совместимость с сетью при отклонениях напряжения ±10 %.

## Чего профили не делают

* Не задают пороги импульсов и N-G — единого норматива нет; оставьте значения под объект
  (заводские 200 Вп / 10 В / 100 Вп).
* Не заменяют измерение по ГОСТ/EN: стандарты оперируют статистикой (P95 по 10-минутным RMS
  за неделю), а VR101 фиксирует каждое превышение порога. Много событий по профилю ±10 %
  не означает несоответствие норме — это повод смотреть глубже.
* Не учитывают фактический режим вашей сети: если постоянно 210 В, профиль ±5 % даст поток
  событий, а ±10 % будет молчать.

## Проверено на живом приборе

Профиль «★ Арбитраж — ГОСТ 32144-2013: ±10 % / ±0,2 Гц» записан в регистратор F28045 и
проверен чтением заголовка: Sag 198 В, Swell 242 В, частотные слова `0x0485`/`0x047B`
(49.78 / 50.22 Гц), описание пустое, журнал очищен.

Отдельно про канал N-G: измеренное мультиметром напряжение нейтраль–земля (≈0,32 В) **ниже
разрешения прибора** (по документации диапазон 3…200 В, шаг 1 В), поэтому и оригинальная
программа EventView, и этот клон показывают 0 В — это корректно.
